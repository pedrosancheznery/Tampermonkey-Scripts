Printmon HOU3 is a tool that allows printing from Windows to Zebra printers. Specifically, this version of Printmon is intended for use with the Zebra ZDesigner GX430t printer, though it can probably be used with any printer that the original Printmon supports. Other printers are currently untested. Printmon HOU3 was designed as an aid primarily for Universal Problem Solvers at HOU3, but can be adapted for use by anyone who uses the original version of Printmon. It is not a replacement for the original tool, but rather a convenient set of add-ons that speed up repetitive common tasks. Many thanks to Ryan Schimer and Jeff Conner for creating the original tool, which this version uses as a backend.
